# Matching Model Architecture

## Feature Engineering
We compute pairwise similarity vectors between candidates generated by the blocking stage.
- **Name/Address:** Token Jaccard, SequenceMatcher ratio, exact equality checks.
- **Numbers:** Overlap of digit strings within addresses.
- **Country:** 1.0 for match, 0.0 for mismatch, 0.5 for missing data. It handles string equality directly to support unseen `France` test labels dynamically.

## Model
We use a custom NumPy-based Logistic Regression model.
- **No external ML libraries:** Avoids `sklearn` bloat.
- **Scoring:** The sigmoid function produces a confidence probability `[0, 1]` for each S1-candidate pair.
- **Thresholding:** We sweep thresholds post-training. We heavily favor high thresholds (e.g., 0.85) because the competition metric (F0.5) applies a massive penalty to false merges, especially for singletons.
